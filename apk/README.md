# apk/

공모전 제출용 release APK를 이 폴더에 둡니다.

- 파일 이름: `팀명_CarRelay_release.apk` (공식 안내 형식: `팀명_앱이름_release.apk`, 팀명은 영어 권장)
- 실행 가능한 **release** 버전이어야 합니다.
- GitHub 업로드 용량을 넘으면 GitHub Releases 에 올리고 Release 페이지 주소를 제출합니다.
- 만드는 방법: [docs/01_개발환경_세팅.md 8번](../docs/01_개발환경_세팅.md#8-제출용-release-apk)
- 서명 키(`*.jks`)는 이 저장소에 올리지 않습니다.

# 01. 개발환경 세팅 (Windows 기준)

이 PC에는 2026-10-27 기준으로 **JDK·Android Studio·Android SDK가 설치되어 있지 않습니다.** 아래 순서대로 한 번만 하면 됩니다.

## 1. Android Studio 설치

1. https://developer.android.com/studio 에서 최신 안정판을 받아 설치합니다.
2. 처음 실행하면 Setup Wizard가 Android SDK를 함께 설치합니다. **Standard** 로 진행하면 됩니다.
3. JDK는 따로 설치하지 않아도 됩니다. Android Studio에 들어 있는 JBR(JDK 17 이상)을 씁니다.

> BIOS에서 가상화(Intel VT-x / AMD-V)가 꺼져 있으면 에뮬레이터가 뜨지 않습니다.
> 에뮬레이터 실행이 막히면 Windows 기능에서 **Windows 하이퍼바이저 플랫폼**을 켜고 재부팅하세요.

## 2. 프로젝트 열기

1. Android Studio → **Open** → `현대자동차 카릴레이` 폴더 선택
2. 오른쪽 아래 Gradle Sync가 끝날 때까지 기다립니다. 처음에는 Gradle 8.10.2, AGP 8.8.2, 라이브러리를 내려받느라 몇 분 걸립니다.
3. Sync가 JDK 오류로 실패하면: **Settings → Build, Execution, Deployment → Build Tools → Gradle → Gradle JDK** 를 `jbr-17` 이상으로 고릅니다.
4. **SDK Manager → SDK Platforms** 에서 **Android 15 (API 35)** 가 설치되어 있는지 확인합니다(compileSdk 35).

## 3. Pleos Connect Emulator 설치

공식 안내: https://document.pleos.ai/en/docs/connect/guide/getting-started/application-development/setup-connect-sdk-emulator

1. **SDK Manager → SDK Update Sites** 탭 → `+`
   - Name: `Pleos Connect System Image`
   - URL (Windows/Linux): `https://nexus-playground.pleos.ai/repository/raw-releases/connect-avd/2.x/crp-sys-img.xml`
2. **SDK Platforms** 탭 → 오른쪽 아래 **Show Package Details** 체크 → **Android API 34** 아래 **Pleos Connect v2.1.0 APIs Intel x86_64 Atom System Image** 체크 → OK
   (설치 창에 `system-images;android-34;pleos_car_emulator;x86_64` 로 표시됩니다. 이전 버전이 깔려 있으면 먼저 지우세요.)
3. Android Studio 재시작
4. **Device Manager → Create Device**
   - Form Factor: **Automotive** → **Pleos Connect v2.1.0**
   - Advanced Settings → Default boot: **Cold** (Quick boot면 VHAL이 동작하지 않습니다)
   - RAM: **4 GB**
   - System Image: API 34, Pleos Connect v2.1.0 APIs → Finish
5. Device Manager에서 ▶ 로 AVD 실행. 기본 언어는 한국어입니다.

> Pleos 에뮬레이터가 아직 준비되지 않았다면, SDK Manager의 일반 **Android Automotive** 이미지로 만든 AVD에서도 **가상 차량 모드**로 앱 전체 흐름을 볼 수 있습니다.

## 4. 앱 실행

1. 위쪽 실행 구성에서 `app-vehicle` 을 고르고 ▶
2. 화면 오른쪽 **가상 차량** 패널로 기어·속도·연료·경고등·문을 바꿉니다.
3. 시연 순서는 [README의 시나리오](../README.md#시연-순서-시나리오-a-주말-장거리-여행)를 따릅니다.

## 5. 두 가지 실행 모드

`gradle.properties` 의 한 줄로 바꿉니다. 바꾼 뒤에는 **Sync Now** 를 누르세요.

| 설정 | 차량 데이터 | 쓰는 곳 |
|---|---|---|
| `carrelay.pleosSdk=false` (기본) | 가상 차량 (`FakeVehicleGateway`) | 어떤 AVD에서나 시연, UI 개발 |
| `carrelay.pleosSdk=true` | Pleos Vehicle SDK + AAOS Car API (`PleosVehicleGateway`) | Pleos AVD + Virtual Console, 실차 |

### Pleos SDK 켜기 체크리스트 (10/25 API 스파이크)

1. `carrelay.pleosSdk=true` → Sync. `ai.pleos.playground:Vehicle:2.3.2` 가 내려받아지는지 확인
2. `app-vehicle/src/pleos/kotlin/.../PleosVehicleGateway.kt` 를 열어 **import 빨간 줄을 Alt+Enter 로 정리** (세부 패키지 경로는 문서에서 확인하지 못해 추정값입니다)
3. Pleos 문서 API Reference에서 Fuel / EvBattery / Safety / Odometer / Brake 함수 이름을 찾아 `readStatus()` 의 TODO를 채웁니다
4. Pleos Connect Virtual Console로 문·기어·속도·연료·경고등을 바꾸며 값이 앱에 들어오는지 확인
5. **확인된 신호만** README의 SDK 표에 '검증됨'으로 바꿉니다. 들어오지 않는 신호는 빼고, 목업과 SDK 연동을 구분해 발표합니다.

## 6. 테스트

- 차량 없이 PC에서 핵심 로직 테스트: `core/src/test` 폴더 우클릭 → **Run 'Tests in core'**
- 터미널: `gradlew :core:test` (아래 7번으로 gradlew 를 만든 뒤)

## 7. gradlew(명령줄 빌드) 만들기

이 저장소에는 아직 `gradlew` 스크립트가 없습니다. 첫 Sync가 끝나면 한 번만:

- Android Studio 오른쪽 **Gradle** 창 → `CarRelay` → Tasks → build setup → **wrapper** 더블클릭

생긴 `gradlew`, `gradlew.bat`, `gradle/wrapper/gradle-wrapper.jar` 를 커밋합니다. 심사위원이 받아서 바로 빌드할 수 있게 하기 위함입니다.

## 8. 제출용 release APK

1. **Build → Generate Signed App Bundle or APK → APK**
2. 새 keystore를 만들고 **저장소 밖**에 보관합니다(`.gitignore` 가 `*.jks` 를 막고 있음).
3. release 로 빌드 → 생성된 APK를 `apk/팀명_CarRelay_release.apk` 로 복사
   (공식 형식 `팀명_앱이름_release.apk`. 팀명은 영어로 쓰면 GitHub 주소가 깨지지 않습니다.)
4. 새 AVD에 설치해서 실행되는지 확인합니다.
5. README 의 [APK](../README.md#apk) 표에서 '상태'를 실제 파일로 바꿉니다.
   APK 가 GitHub 업로드 용량을 넘으면 GitHub Releases 에 올리고 그 Release 페이지 주소를 제출합니다.

### 공모전 GitHub 제출 체크

- [ ] README 에 앱 이름·한 줄 소개, 실행 방법, 테스트 환경 및 필요한 설정, APK 위치가 있다
- [ ] `apk/` 에 실행 가능한 **release** APK 가 있다
- [ ] 비공개로 제출하면: 공지된 **심사용 GitHub 계정을 Collaborator 로 초대**하고, 그 계정으로 접근되는지 마감 전에 확인
  (개인 계정의 비공개 저장소는 Collaborator 에게 **쓰기 권한도** 줍니다. 원치 않으면 제출 직전 공개로 전환)
- [ ] 제출 페이지에 저장소 주소와 APK 경로를 입력했다

## 9. GitHub에 올리기 전 확인

공모전 안내: 공유 링크와 첨부자료에 **개인정보·계정정보·개발자 실명**이 보이지 않아야 합니다.

- 커밋 작성자 이메일이 개인 메일이면 커밋 기록에 남습니다. 이 저장소에서만 바꾸려면:
  ```bash
  git config user.email "<GitHub 계정의 noreply 주소>"
  ```
  (GitHub → Settings → Emails → "Keep my email addresses private" 에서 noreply 주소 확인)
- `참고자료/` 폴더(신청서 원본)는 `.gitignore` 로 제외되어 있습니다.
- README·코드·스크린샷에 이름·전화번호·이메일이 없는지 확인합니다.
- 저장소를 비공개로 둘 경우, 심사 기간에 접근 권한을 어떻게 줄지 공식 안내를 확인합니다.

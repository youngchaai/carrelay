# 01. 개발환경 세팅 (Windows 기준)

아래 순서대로 한 번만 하면 됩니다. (2026-10-27: Android Studio Rabbit 1 설치, core 테스트 32개 통과, 차량 앱 빌드 성공 확인)

## 0. Windows 사용자 이름이 한글이면 (중요)

`C:\Users\홍길동` 처럼 사용자 폴더에 한글이 있으면 빌드가 실패합니다.

- 프로젝트 경로에 한글 → Android 빌드 도구가 시작부터 막음 ("Your project path contains non-ASCII characters")
- Gradle 폴더(`C:\Users\<한글>\.gradle`)에 한글 → 테스트 실행 시 `ClassNotFoundException: GradleWorkerMain`

해결 (이 저장소에서 적용한 방법):

1. 프로젝트를 영문 경로에 둡니다: **`C:\dev\carrelay`**
2. 사용자 환경 변수 **`GRADLE_USER_HOME=C:\dev\.gradle`** 을 추가하고 Android Studio 를 다시 켭니다.
   ```powershell
   [Environment]::SetEnvironmentVariable("GRADLE_USER_HOME", "C:\dev\.gradle", "User")
   ```
3. **Android SDK 와 가상 기기(AVD)도 영문 경로로** 옮겨야 에뮬레이터가 켜집니다. 한글 경로에 있으면 에뮬레이터가 부팅 중 멈추고 Studio 는 "Emulator failed to connect within 5 minutes" 를 띄웁니다.
   - SDK: `C:\dev\android-sdk` (Studio 를 끈 상태에서 폴더를 옮기고, Settings → Languages & Frameworks → Android SDK 위치를 맞춤)
   - AVD: `C:\dev\android-avd`
   - 사용자 환경 변수: `ANDROID_HOME=C:\dev\android-sdk`, `ANDROID_AVD_HOME=C:\dev\android-avd`
   - 프로젝트 `local.properties`: `sdk.dir=C\:\\dev\\android-sdk`

## 1. Android Studio 설치

1. https://developer.android.com/studio 에서 최신 안정판을 받아 설치합니다.
2. 처음 실행하면 Setup Wizard가 Android SDK를 함께 설치합니다. **Standard** 로 진행하면 됩니다.
3. JDK는 따로 설치하지 않아도 됩니다. Android Studio에 들어 있는 JBR(JDK 17 이상)을 씁니다.

> BIOS에서 가상화(Intel VT-x / AMD-V)가 꺼져 있으면 에뮬레이터가 뜨지 않습니다.
> 에뮬레이터 실행이 막히면 Windows 기능에서 **Windows 하이퍼바이저 플랫폼**을 켜고 재부팅하세요.

## 2. 프로젝트 열기

1. Android Studio → **Open** → `C:\dev\carrelay` 폴더 선택
2. 오른쪽 아래 Gradle Sync가 끝날 때까지 기다립니다. 처음에는 Gradle 8.10.2, AGP 8.8.2, 라이브러리를 내려받느라 몇 분 걸립니다.
3. **Gradle JDK 는 17~23** 이어야 합니다. Android Studio 내장 JDK 25 는 Gradle 8.10.2 가 지원하지 않습니다.
   **Settings → Build, Execution, Deployment → Build Tools → Gradle → Gradle JDK** 에서 `jbr-21` 을 고릅니다
   (호환 JDK 가 없으면 Studio 가 내려받기를 제안합니다).
4. Android 15 (API 35) SDK 와 Build-Tools 35 는 첫 빌드 때 자동으로 설치됩니다.

## 3. Pleos Connect Emulator 설치

공식 안내: https://document.pleos.ai/en/docs/connect/guide/getting-started/application-development/setup-connect-sdk-emulator

1. **SDK Manager → SDK Update Sites** 탭 → `+`
   - Name: `Pleos Connect System Image`
   - URL (Windows/Linux): `https://nexus-playground.pleos.ai/repository/raw-releases/connect-avd/2.x/crp-sys-img.xml`
2. **SDK Platforms** 탭 → 오른쪽 아래 **Show Package Details** 체크 → **Android API 34** 아래 **Pleos Connect v2.1.0 APIs Intel x86_64 Atom System Image** 체크 → OK
   (설치 창에 `system-images;android-34;pleos_car_emulator;x86_64` 로 표시됩니다. 이전 버전이 깔려 있으면 먼저 지우세요.)
3. Android Studio 재시작
4. **Device Manager → Create Device**
   - Form Factor: **Automotive** → **Pleos Connect v2.1.0**
   - Advanced Settings → Default boot: **Cold** (Quick boot면 VHAL이 동작하지 않습니다)
   - RAM: **4 GB**
   - System Image: API 34, **Pleos Connect v2.1.0 APIs** → Finish
     (기본값이 일반 "Android Automotive" 이미지로 잡힐 수 있으니 꼭 확인하세요)
   - SDK Update Sites 에 넣은 주소가 저장되지 않으면 이미지가 목록에 안 보입니다. 이때는
     `%USERPROFILE%\.android\repositories.cfg` 에 `src00=https\://nexus-playground.pleos.ai/...crp-sys-img.xml` 이 있는지 확인하세요.
5. Device Manager에서 ▶ 로 AVD 실행. 기본 언어는 한국어입니다.

> Pleos 에뮬레이터가 아직 준비되지 않았다면, SDK Manager의 일반 **Android Automotive** 이미지로 만든 AVD에서도 **가상 차량 모드**로 앱 전체 흐름을 볼 수 있습니다.

## 4. 앱 실행

1. 위쪽 실행 구성에서 `app-vehicle` 을 고르고 ▶
2. 화면 오른쪽 **가상 차량** 패널로 기어·속도·연료·경고등·문을 바꿉니다.
3. 시연 순서는 [README의 시나리오](../README.md#시연-순서-시나리오-a-주말-장거리-여행)를 따릅니다.

## 5. 두 가지 실행 모드

`gradle.properties` 의 한 줄로 바꿉니다. 바꾼 뒤에는 **Sync Now** 를 누르세요.

| 설정 | 차량 데이터 | 쓰는 곳 |
|---|---|---|
| `carrelay.pleosSdk=false` (기본) | 가상 차량 (`FakeVehicleGateway`) | 어떤 AVD에서나 시연, UI 개발 |
| `carrelay.pleosSdk=true` | Pleos Vehicle SDK + AAOS Car API (`PleosVehicleGateway`) | Pleos AVD + Virtual Console, 실차 |

### Pleos SDK 빌드와 Virtual Console (10/29 검증 완료)

1. 빌드: Android Studio 에서 `carrelay.pleosSdk=true` → Sync, 또는 명령줄에서 `gradlew.bat :app-vehicle:assembleDebug "-Pcarrelay.pleosSdk=true"` (PowerShell 은 따옴표 필요)
2. 설치 후 속도·위치 권한 허용: 첫 실행 때 묻는 두 창에서 **허용**. 명령줄로는 `adb shell pm grant --user 10 com.carrelay.vehicle android.car.permission.CAR_SPEED` 와 `... pleos.car.permission.FUSED_LOCATION` (Pleos 에뮬레이터의 운전자 사용자는 10번입니다. `adb shell am get-current-user` 로 확인)
3. Virtual Console 열기: `adb forward tcp:8088 tcp:8088` → PC 브라우저에서 `http://127.0.0.1:8088/` → 왼쪽 아래 **Emulation Controls**
4. 바꿔 볼 값
   - `Energy` → **Battery SOC**, **Remaining Range** : 홈·브리핑의 배터리 %, 갈 수 있는 거리가 바로 바뀜
   - `All domains` → **Gear Selection** D / P : 주행 화면 / "주차하셨네요"
   - `All domains` → **Door Position** (Front left) Open → Close : "운전하는 분이 바뀌었나요?"
   - `Motion` → **Brake Pedal**, **Odometer** : 브레이크 눌림, 누적 주행거리(km)
   - 달리기: 기어 D → 첫 화면 **ACCEL** 을 누르고 있으면 속도가 오름(가속 페달). **BRAKE** 를 꾹 누르면 급정거 → 기어 P → "운전 중 급정거가 1번 있었어요"
   - 크루즈(ADAS → Longitudinal)만 켜서는 차가 움직이지 않습니다. 콘솔이 "DDS unavailable"로 바뀌면 페이지를 새로고침하세요.
5. 받을 수 없는 것: 계기판 경고등(Telltales)과 타이어 공기압 값은 `PRIVATE_CAR_SAFETY` 권한이 필요해 서드파티 앱은 못 받습니다(콘솔에서 켜도 앱에는 오지 않음). 앱은 "경고등 정보: 이 앱에서는 볼 수 없어요"로 표시합니다.
6. 참고: Pleos 에뮬레이터는 user 빌드라 `cmd car_service inject-vhal-event` 같은 명령줄 주입은 막혀 있습니다. 값은 Virtual Console 로만 바꿉니다.
7. 앱 데이터 초기화: `adb shell pm clear --user 10 com.carrelay.vehicle` (`--user` 없이 하면 0번 사용자만 지워집니다)
8. 휴게소 안내 시험(케어 모드): 설정 → **빠른 판단** 켜기 → 할아버지 선택 → 콘솔 기어 **D**(속도 0, 조작 없음) → 약 15초 뒤 "괜찮으세요?" → 10초 무응답 → Pleos 내비가 가까운 졸음쉼터로 안내 시작 → 10초 뒤 보호자 알림(현재 주소). 시험 뒤 내비 화면에서 **안내 종료**.
9. 기어 D 상태에서 앱을 새로 띄우면 시스템이 "주행 중에는 사용할 수 없습니다"로 가릴 수 있습니다(adb 설치 앱). 콘솔을 P 로 두고 다시 실행하세요. Pleos 문서의 `hmg_car_service ... driving_regulation off` 는 실차 전용이라 에뮬레이터에는 없습니다.
10. 빌드 옵션(`carrelay.pleosSdk`)을 바꿔 가며 빌드할 때는 처음 한 번 `gradlew.bat :app-vehicle:clean` 을 권합니다.
11. **말로 남기는 메모 (SpeechToText):**
    - 권한 `pleos.car.permission.STT_SERVICE` 는 일반 권한이라 설치하면 자동으로 허용됩니다.
    - 에뮬레이터 마이크를 쓰려면 에뮬레이터 패널 **⋯ (Extended Controls) → Microphone** 에서 **Virtual microphone uses host audio input** 을 켭니다. PC 에 마이크가 있어야 합니다.
    - 마이크 없이 시험할 때(디버그 빌드만): 16kHz·16bit·mono PCM 파일을 앱 폴더에 넣고 **말로 남기기**를 누르면, 마이크 대신 그 소리로 인식합니다. 한 번 쓰면 지워집니다.
      ```
      adb push voice.pcm /data/local/tmp/voice_test.pcm
      adb shell run-as com.carrelay.vehicle --user 10 cp /data/local/tmp/voice_test.pcm files/voice_test.pcm
      ```
      Windows 에서는 기본 한국어 음성(Microsoft Heami)으로 이런 파일을 만들 수 있습니다(`System.Speech`, 16kHz mono 로 저장 후 WAV 머리 44바이트 제거).

## 8. 제출용 release APK

서명 키는 **저장소 밖** `C:\dev\carrelay-keys\` 에 있습니다(`.gitignore` 가 `*.jks`·`keystore.properties` 도 막음).
2026-11-09 에 **새 키로 바꿨습니다**(백업 USB 분실 가능성 때문). 새 인증서 SHA-256 `D1:4B:1D:…:3C:F1`, 이전 키(`79:AD:AF:…:88:B4`)는 같은 폴더의 `old_2026-10-29\` 에 보관만 하고 쓰지 않습니다. 이전 키로 서명된 APK 는 더 이상 제출용이 아닙니다.

| 파일 | 내용 |
|---|---|
| `carrelay-release.jks` | 서명 키 (PKCS12, RSA 2048, 별칭 `carrelay`, 유효 10,000일, `CN=CarRelay`) |
| `keystore.properties` | `storeFile` · `storePassword` · `keyAlias` · `keyPassword` |

> 이 폴더는 **다른 곳에 꼭 백업**하되, 암호를 건 곳에만 두세요(암호 걸린 압축 파일, 비밀번호 관리자 등). 그냥 USB 에 넣어 두면 잃어버렸을 때 키와 비밀번호가 함께 새어 나갑니다. 키를 잃으면 같은 앱으로 업데이트할 수 없습니다(App Market 배포 시 중요).
> 다른 PC 에서 빌드할 때는 이 폴더를 저장소 옆(`../carrelay-keys`)에 두거나 `-Pcarrelay.signing=경로\keystore.properties` 로 알려 줍니다. 파일이 없으면 서명하지 않은 APK 가 만들어집니다.

1. 두 가지 release 빌드를 만듭니다.
   ```
   gradlew.bat :app-vehicle:assembleRelease "-Pcarrelay.pleosSdk=true"
   copy app-vehicle\build\outputs\apk\release\app-vehicle-release.apk apk\영차_CarRelay_release.apk
   gradlew.bat :app-vehicle:assembleRelease
   copy app-vehicle\build\outputs\apk\release\app-vehicle-release.apk apk\영차_CarRelay_virtual_release.apk
   ```
2. 서명 확인: `apksigner verify --print-certs apk\영차_CarRelay_release.apk` → `CN=CarRelay`
3. 새 AVD에 설치해서 실행되는지 확인합니다. 디버그 빌드가 깔려 있으면 서명이 달라 먼저 `adb uninstall com.carrelay.vehicle`.
4. 파일 이름은 공식 형식 `팀명_앱이름_release.apk` 를 따릅니다(팀명 `영차`, 앱 이름 `CarRelay`, 11/13 확정).

APK 크기를 줄이려고 차량·에뮬레이터에서 쓰는 CPU(`arm64-v8a`, `x86_64`)만 넣고 코드를 압축해 담습니다(Pleos 빌드 17.6MB). Pleos SDK 가 AIDL·리플렉션을 써서 코드 축소(R8)는 끕니다.

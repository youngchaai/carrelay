## 녹화·편집 방법 (자동)

스크립트: `C:\dev\carrelay-video\scripts` (README.txt 참고)

1. 에뮬레이터 Cold boot → `adb forward tcp:8088 tcp:8088` → Pleos **디버그** 빌드 설치(말 메모 음성 파일 주입·연속 운전 앞당기기는 디버그 빌드에만 있음).
2. `record.ps1`: 장면마다 `adb shell screenrecord` 로 녹화하면서 화면을 누르고, Virtual Console 은 HTTP(`PUT /vehicle/gear`, `/vehicle/controls`, `/vehicle/ev-battery`, `/vehicle/body`)로 바꿉니다.
   - 콘솔 서버는 브라우저가 연결돼 있어야(`POST /browser/session`) 값을 받으므로, 스크립트가 3초마다 이 신호를 보냅니다. 콘솔 웹 페이지는 자체 속도 계산으로 값을 덮어쓰므로 **닫아 둡니다.**
   - 급정거는 속도를 1초 동안 60 → 0 으로 나눠 보냅니다(한 번에 0 으로 바꾸면 감지기가 비교할 이전 값이 없음).
   - 화면 터치 표시: `adb shell settings --user 10 put system show_touches 1`
3. `assemble.ps1`: 장면별로 자르고(기다리는 구간은 빠르게), 자막(Pretendard)·라벨·내레이션을 넣어 하나로 합칩니다(ffmpeg). 자막·구간은 `video_cfg.ps1` 에서 고칩니다.

# 05. 시연 영상 대본

목표 길이 **약 3분**. 공식 안내상 목업·프로토타입·화면 녹화 모두 인정됩니다.

## 원칙

- **차량 화면은 실제 앱을 녹화**합니다(가상 차량 모드 또는 Pleos Virtual Console). 목업보다 '실제로 만들었다'는 증거가 됩니다.
- **폰 화면은 목업**입니다(아직 코드 없음). 해당 장면 화면 구석에 **"목업 · 개발 예정"** 라벨을 넣습니다.
- 가상 차량 장면에는 **"실제 앱 · 가상 차량 데이터"** 라벨을 넣습니다. 에뮬레이터 값을 실차 데이터처럼 말하지 않습니다.
- 수치(수면 시간, 거리)는 시나리오 예시입니다. 효과를 검증된 사실처럼 말하지 않습니다.

## 녹화 전 준비

- [ ] 에뮬레이터: Pleos Connect v2.1.0 AVD (없으면 일반 Automotive AVD), 언어 한국어
- [ ] 앱 설정 → **기록 초기화** (깨끗한 시연용 파티로 시작)
- [ ] 앱 설정 → **음성 안내** 켜기 (한국어 TTS 가 없으면 자막으로 대신)
- [ ] 화면 오른쪽 **가상 차량** 패널 열기 (차량 값을 바꾸는 장면이 보이도록)
- [ ] 폰 목업: Claude 아티팩트 "카릴레이 폰 앱 목업"을 열고 각 화면의 **Play** 로 클릭 동작 녹화
- [ ] 녹화 도구: Windows **Win + Alt + R** (Xbox Game Bar) 또는 OBS, 1080p

## 선택 장면 (Pleos SDK 연동이 확인되면 추가)

| 장면 | 화면 | 내용 |
|---|---|---|
| SDK 증거 | Pleos AVD + **Virtual Console** | `carrelay.pleosSdk=true` 빌드에서 Virtual Console 로 문·기어를 바꾸면 앱이 반응하는 장면. 심사 질문 "SDK를 실제로 썼나요?"에 대한 답이 됩니다. |
| 신뢰성 | 차량 앱 | 앱 강제 종료 후 재실행 → 메모와 진행 중 운전이 그대로 남아 있음 |
| 미지원 처리 | 차량 앱 | 가상 차량 패널 **연료 정보 지원** 끄기 → 브리핑에 "이 차량은 지원하지 않아요" |
| 사고·파손 (시나리오 C, 약 25초) | 차량 앱 | 아빠 `D` → `60` → **급정거** → `P` → "차에 이상이 있나요?" → **있어요** → **긁힘 · 앞·왼쪽** 남기기 → 엄마 브리핑 맨 위 "아직 고치지 않았어요" → **처리하기 → 수리·보험 맡겼어요**. 내레이션: "급정거가 있었으면 주차 후 바로 묻고, 신고한 파손은 처리될 때까지 다음 운전자에게 계속 보여 줍니다. 누구 탓인지는 정하지 않습니다." 3분을 넘기면 A-5 교대 감지를 줄입니다. |

## 반드시 재현할 실패 상황

- [ ] 운전자를 선택하지 않고 출발 → '미확인' 기록, 직전 운전자 기록에 섞이지 않음
- [ ] 지원하지 않는 센서 → 브리핑에 "지원하지 않아요" (가상 차량: '연료 정보 지원' 끄기)
- [ ] 오래된 값 → "N분 전 값이에요"
- [ ] 네트워크 끊김 → 로컬 저장으로 메모 유지
- [ ] 앱 강제 종료 후 재실행 → 메모·진행 중 운전 구간 복원
- [ ] 주차 → 주행 전환 시 선택·메모 화면이 숨겨짐
- [ ] 읽음 처리 후에도 미해결 메모가 남음
- [ ] 메모를 해결해도 현재 경고등이 사라지지 않음
- [ ] 사고·파손 신고 후 처리 완료 전까지 다음 운전자 브리핑 맨 위에 계속 표시
- [ ] 급정거 없이 주차하면 "차에 이상이 있나요?"를 묻지 않음
- [ ] 같은 사람이 이어서 타면 인수 점검 발견 건에 '직전 운전자'가 붙지 않음
